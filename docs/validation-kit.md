# Independent validation kit

Status: prepared protocol, not a completed study. Use fictional data only for this prototype.

## Language review

Recruit a fluent speaker for each of Hindi, Tamil, Telugu and Kannada. Review every localized instruction, missing-detail question and native sample. For six speech scenarios per language, compare original intent, audio, ASR text and English translation. Independently mark preserved / altered / omitted for symptom denials, timing, uncertainty, medication names, numbers and units. Record exact errors and approved replacement wording. Same-provider synthesized audio does not establish human speech accuracy.

## Clinician review

A qualified independent reviewer examines the original, English version and exported handoff for each case. Record extra or omitted facts, wrong category, lost negation, incorrect medication quantity, allergy scope and unresolved contradictions. Adjudicate author labels before reporting clinically meaningful accuracy. Have a second reviewer resolve disagreements. The self-attested app acceptance is only a workflow demonstration.

## Timing comparison

Use at least ten matched fictional cases and several independent intake workers. Counterbalance manual-first and assisted-first order to reduce learning effects. Use the same case ID for both measurements; time the complete reviewed handoff, including corrections and failures. Report sample size, median paired difference, spread, error count and failure rate. Do not extrapolate a self-timed demonstration to clinic efficiency.

## Observation form

Record: reviewer reference and role; language fluency; case ID; workflow order; manual seconds; assisted seconds; corrections; critical errors; unresolved details; acceptance/rejection; comments. Avoid personal health data. Do not call a prepared form or demo acceptance actual external validation.
